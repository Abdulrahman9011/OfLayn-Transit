# OfLayn — نسخة بدون إنترنت (Offline-First)

إعادة بناء كاملة لتطبيق مواصلات بورصة. التطبيق يفتح الآن **بمحتوى كامل من أول فتحة وبدون إنترنت**،
والمساعد الذكي **مدمج ويعمل محلياً** بدون مفتاح ولا توكن ولا تحميل نموذج.

## 1. المبدأ المعماري

```
assets/offline/network.json.gz       407 خط · 7549 محطة  (مدمجة داخل الـAPK)
assets/offline/day_snapshot.json.gz  لقطة رحلات حقيقية (بذرة أول تشغيل)
            │
            ▼  أول تشغيل: تُنسخ اللقطة إلى تخزين الهاتف
data/data/com.oflayn.transit/files/day_trips.json     ← رحلات اليوم (Timestamp + TTL)
            │
            ▼
   TripsEngine.board()   ← قراءة فورية من الذاكرة/الملف (لا شبكة أبداً)
   TripsEngine.refresh() ← عند وجود إنترنت فقط: تسحب رحلات كل الخطوط وتدمجها
            │
            ├── TodayScreen  : رحلات اليوم القادمة + وسم "متصل/بدون إنترنت" + عمر البيانات
            ├── LinesScreen  : بحث فوري في 407 خط و 7549 محطة (محلي)
            ├── LineDetail   : كل الخطوط + اتجاهاتها + تتابع المحطات + رحلاتها
            ├── StopScreen   : كل الخطوط التي تخدم المحطة + رحلاتها القادمة
            └── AiScreen     : OfflineAssistant (محلي بالكامل)
```

## 2. ماذا تغيّر

| قبل | بعد |
|---|---|
| التطبيق يطلب رابط خادم + توكن + مفتاح Gemini من المستخدم | لا يوجد أي حقل مفتاح أو توكن. المساعد يعمل من أول فتحة |
| تحميل نموذج Gemma 4 E2B (~2.6 GB) ليعمل الذكاء الاصطناعي | لا تحميل. المساعد مدمج ويعمل بدون إنترنت |
| الخطوط والمحطات تُجلب من Overpass عند الطلب (تحتاج إنترنت) | 407 خط و 7549 محطة مدمجة في الـAPK |
| لا توجد رحلات/مواعيد محلية | رحلات اليوم تُحفظ على الهاتف وتُعرض حسب المدة |
| لا شاشة "رحلات اليوم" | `TodayScreen` هي الشاشة الافتراضية |
| Kotlin DSL + 6 وحدات + Room + MapLibre + LiteRT-LM | مشروع أصغر: `app` + `domain:trips` (Kotlin نقي) |
| لا يمكن اختبار المنطق خارج الجهاز | `tools/verify` يختبر النواة على JVM: **31 فحصاً، 0 فشل** |

## 3. مصدر البيانات

خدمة **BursaKart الرسمية** «أين حافلتي» (`bursakartapi.abys-web.com`) — نفس الخدمة التي يستدعيها موقع
المشغّل `bursakart.com.tr/wheremybus`:

| الغرض | المسار | الحقول المستخدمة |
|---|---|---|
| فهرس الخطوط | `static/routeandstation` | `kod`, `aciklama`, `hatNo` |
| محطات الخط واتجاهاته | `static/routestat` | `stopId, stopName, sequence, latitude, longitude, direction` |
| رحلات اليوم (الوقت المتبقي) | `static/stationremainingtime` | `routeCode, routeTitle, passTime, licencePlate, direction` |

`passTime` هو الوقت المتبقي للمركبة المتجهة إلى المحطة ⇒ وقت المرور = الآن + الوقت المتبقي.
كل رحلة مُشتقة بهذه الطريقة تُوسم **OBSERVED (رحلة حقيقية اليوم)** مع رقم اللوحة.

### وسوم الرحلات (لا شيء يُقدَّم كجدول رسمي بغير دليل)
| الوسم | المعنى | المصدر |
|---|---|---|
| `OFFICIAL` | جدول رسمي منقول حرفياً | المشغّل |
| `OBSERVED` | رحلة حقيقية رصدتها الخدمة الرسمية اليوم | `stationremainingtime` + لوحة المركبة |
| `ESTIMATED` | مشتقة من تواتر نفس الخط | حساب محلي، **موسومة دائماً بأنها تقديرية** |

## 4. "حسب المدة" (صلاحية البيانات)

`FreshnessPolicy` — الافتراضي 6 ساعات، قابل للتغيير من «المزيد» (1/3/6/12/24 ساعة):

| العمر | الحالة | ما يظهر |
|---|---|---|
| داخل المدة | `FRESH` | «محفوظة على الهاتف · عمرها …» |
| حتى ضعف المدة | `STALE` | «بيانات قديمة · …» |
| أكثر من ذلك | `EXPIRED` | «بيانات منتهية · …» |
| لا شيء محفوظ | `EMPTY` | «لا توجد رحلات محفوظة» |

لقطة من يوم سابق لا تُعرض أبداً كأنها اليوم: `board.dayIso != today` ⇒ تُعلَّم منتهية.

## 5. المساعد الذكي المدمج

`OfflineAssistant` — محرك محلي بالكامل (قواعد + بحث مفهرس)، بدون شبكة وبدون أي LLM سحابي:

- `موعد 31A القادم` ⇒ أقرب رحلة محفوظة + الوقت + اللوحة
- `محطات 31A` ⇒ تتابع المحطات
- `كم عدد رحلات 99 اليوم` ⇒ عدّ الرحلات
- `شو الخطوط على محطة سيتيلر باركي` ⇒ كل الخطوط التي تخدم المحطة
- أي سؤال غير مفهوم ⇒ يشرح ما يستطيع فعله (لا يخترع بيانات)

يبحث بأسماء المحطات مع تطبيع تركي/عربي (ç/ş/ğ/ı، والتشكيل والألف بأشكالها).

## 6. البناء

```bash
# الطريقة الأسهل: افتح المجلد في Android Studio (Ladybug+) ثم Run
# أو سطر الأوامر:
./gradlew :app:assembleDebug      # يحتاج Android SDK 35 + JDK 17
./gradlew :app:assembleRelease    # نسخة موقّعة بعد ضبط signingConfig
```

- `compileSdk 35`, `minSdk 26`, `targetSdk 35`, Kotlin 2.0.21, AGP 8.7.2, Compose BOM 2024.10.01
- الأذونات: الإنترنت، حالة الشبكة، الموقع (اختياري — للبحث عن أقرب محطة فقط)
- لا مكتبة ذكاء اصطناعي، لا Room، لا خريطة، لا نموذج: حجم صغير وبناء أسرع

### اختبار النواة بدون جهاز
```bash
kotlinc domain/trips/src/main/kotlin/com/oflayn/domain/trips/*.kt -d core.jar
kotlinc -cp core.jar tools/verify/VerifyMain.kt -d verify.jar

```

## 8. ما لم يُنفَّذ (بصراحة)

- **لا GTFS رسمي**: لم يُعثر على تغذية جداول رسمية لبورصة، فالتطبيق لا يخترع مواعيد.
- **المواعيد الرسمية للخطوط**: تُعرض رحلات اليوم المرصودة فعلياً، لا جدول مُتخيَّل.
- **الخريطة**: أُزيلت في هذه النسخة (MapLibre كان يتطلب شبكة للبلاطات ويخالف مبدأ «يعمل بدون إنترنت»).
- **الحافلات الحيّة على الخريطة**: الخدمة الرسمية لا تنشر مواقع بموجب شروط موثّقة.
- **الرصيد والتنبيهات**: لا API رسمي.
